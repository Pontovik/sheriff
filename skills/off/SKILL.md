Пользователь набрал команду `/sheriff:off`. Режим переключает хук плагина sheriff, не ты.

Найди в контексте строку, которая начинается с `SHERIFF-MODE`. Хук печатает её при каждом срабатывании этой команды. Процитируй строку пользователю дословно.

- **`SHERIFF-MODE off`.** Режим выключен. С этого момента правила режима шерифа не действуют: разведка до кода, обязательные тесты и ревью перед завершением хода больше не требуются, хуки молчат. Общие правила плагина sheriff из начала сессии остаются в силе.
- **`SHERIFF-MODE on`.** Команда не выполнилась, режим остался включён. Перескажи причину из пояснения после строки и продолжай работать по правилам режима.
- **Строки нет.** Хук не сработал: Claude Code не поддерживает событие `UserPromptExpansion` или плагин sheriff установлен неправильно. Скажи это пользователю прямо.

Следующее включение командой `/sheriff:on` создаст новую базу: прошлые проверки на неё не распространяются.
